# Simple Age Calculator

## Overview
A simple, ad-free age calculator website built for my aunt, who needed an easy way to calculate ages for her work. Other calculators were cluttered with ads or had confusing inputs like scrolling through years, so I made this clean and user-friendly for her.

## Features
- Type birthdate (MM/DD/YYYY) to calculate age.
- No ads, no scrolling, just straightforward input.
- Shows age in years, months, and days.
- Works on phones, tablets, or computers.

## How to Use
1. Enter birthdate (e.g., 05/15/1970).
2. Click "Calculate Age" to see the result.
